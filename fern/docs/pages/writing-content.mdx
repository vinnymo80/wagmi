Pages are written in MDX — Markdown plus React components. Add `.mdx` files to `docs/pages/` and reference them in `docs.yml`.

## Quick example

A minimal page with frontmatter and Markdown:

```markdown title="docs/pages/my-page.mdx"
---
title: Page title
subtitle: Optional subtitle
slug: my-page
---

Your content here. Use standard Markdown formatting like **bold**, *italic*, and `code`.

## Headings

Use headings to organize your content.
```

## Using components

Fern ships [built-in components](https://buildwithfern.com/learn/docs/writing-content/components/overview) for common patterns. Each example below shows the rendered output followed by the MDX that produces it.

### Callouts

Draw attention to important information.

<Note>
Highlight important information with callouts.
</Note>
